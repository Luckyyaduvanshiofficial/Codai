## 📊 Technical Specifications

### 🖥️ System Requirements
| Component | Minimum | Recommended |
|-----------|---------|-------------|
| **OS** | Windows 10 (64-bit) | Windows 11 (64-bit) |
| **RAM** | 4GB | 8GB+ |
| **Storage** | 2GB free | 4GB+ (SSD) |
| **CPU** | Dual-core 2.0GHz | Quad-core 2.5GHz+ |

### 🏗️ Architecture
- **Frontend**: CustomTkinter (Modern Python GUI)
- **Backend**: FastAPI (High-performance API)
- **AI Engine**: Llama.cpp (Offline LLM)
- **Build System**: PyInstaller (Portable executable)
- **Deployment**: GitHub Actions (CI/CD)

### 🔒 Security Features
- **Offline Operation** - No data transmission
- **Local Processing** - Code never leaves machine
- **No Telemetry** - Zero data collection
- **Open Source** - Fully auditable code
